# Crystal Cascade 1.4.0 — Cinematic Interaction Pass

- Added curved crystal flight animation between source and destination tubes.
- Added move telemetry to GameProvider so presentation systems can react to real moves.
- Added scene-level coordinates for accurate animation overlay placement.
- Added Guardian gaze tracking toward the active/target tube.
- Added stronger 2.5D glass rim/depth treatment to tubes.
- Kept the existing puzzle rules and progression intact.

## Design intent
The crystal, tube, camera, Guardian, environment and audio should increasingly feel like one reactive world.
