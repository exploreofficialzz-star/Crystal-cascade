# Crystal Cascade — v1.5.0

## Living reaction choreography
- Added a dedicated `ReactionChoreography` visual layer for coordinated match/victory pulses and bursts.
- Strengthened the 2.5D scene camera response with a subtle scale/tilt/rotation kick.
- Added low-move reaction signaling so the Guardian/environment can consistently enter a worried state.
- Kept gameplay rules separate from presentation effects.
- Preserved existing puzzle, progression, hints, restart, shop and reward systems.

## Design goal
A meaningful action should now read as one event across crystal, tube, camera, Guardian, environment and audio instead of a collection of unrelated animations.
